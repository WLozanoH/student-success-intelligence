# Fuentes de datos

## Conjunto de datos

**Nombre:** Predicción de la deserción y el éxito académico de los estudiantes

**Fuente:** Kaggle

https://www.kaggle.com/datasets/thedevastator/higher-education-predictors-of-student-retention

**Fuente original:** Repositorio de Aprendizaje Automático de la UCI (UCI Machine Learning Repository)

https://doi.org/10.24432/C5MC89

## Características del conjunto de datos

- Registros: 4.424
- Variables predictoras: 36
- Variable objetivo: Target
- Clases de clasificación:
- Deserción (Dropout)
- Matriculado (Enrolled)
- Graduado (Graduate)

## Organización de los datos

| Capa | Descripción |
|---|---|
| raw | Conjunto de datos original descargado |
| staging | Datos extraídos y validados |
| processed | Datos analíticos transformados |
